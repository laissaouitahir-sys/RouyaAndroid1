طريقة استخراج APK عبر GitHub Actions (لا تحتاج Android Studio):

1) أنشئ حساباً في GitHub إذا لم يكن لديك حساب.
2) أنشئ مستودعاً جديداً (New repository) باسم RouyaAndroid.
3) ارفع جميع محتويات هذا المجلد إلى المستودع، بما فيها مجلد .github.
4) افتح تبويب Actions في المستودع.
5) اختر Build Rouya APK ثم Run workflow (أو انتظر البناء التلقائي بعد رفع الملفات).
6) بعد نجاح البناء افتح عملية التشغيل المكتملة، وانزل إلى Artifacts.
7) حمّل rouya-debug-apk.zip وافتحه؛ ستجد app-debug.apk.
8) انقل APK إلى هاتف Android وثبّته. قد تحتاج السماح بالتثبيت من هذا المصدر.

مهم:
- هذه نسخة Debug تجريبية وليست إصداراً نهائياً منشوراً على Google Play.
- الواجهة تعمل داخل WebView، وبعض الرسوم تعتمد على اتصال الإنترنت.
- تسجيل الدخول الحقيقي، التخزين السحابي، تحليل الذكاء الاصطناعي، الدفع وأسعار الصرف الحية ليست مفعّلة بعد؛ تحتاج خدمات وربطاً إضافياً.
